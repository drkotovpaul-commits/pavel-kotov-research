# Pavel Kotov — Independent Researcher

Static GitHub Pages site for a public record of research notes, hypotheses, publications, and scientific dialogue.

## Structure

- `index.html` — Home
- `research.html` — AMR research programme
- `notes.html` — research notes
- `hypotheses.html` — hypothesis register
- `publications.html` — publications and research outputs
- `dialogue.html` — open scientific contact
- `templates/` — writing templates for future Notes and Hypotheses

## GitHub Pages

1. Create a new repository.
2. Upload the repository contents to the repository root.
3. Open **Settings → Pages**.
4. Set the source to **Deploy from a branch**.
5. Select the default branch and `/ (root)`.
6. Save.

The site is plain HTML/CSS and requires no build step.

## Editorial principle

The site documents the research; it does not seek to persuade or function as a marketing site.
